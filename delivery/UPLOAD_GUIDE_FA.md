# راهنمای آپلود نسخهٔ اصلاح‌شدهٔ نقشیران

## بستهٔ آماده

فایل **Naghshiran-update.zip** شامل 96 فایل پروژه (33 جایگزینی و 63 فایل جدید) و این راهنما و فهرست دقیق فایل‌هاست. ساختار پوشه‌ها داخل ZIP مطابق ریشهٔ پروژه است.

1. از پروژه و دیتابیس D1 فعلی نسخهٔ پشتیبان بگیرید.
2. ZIP را در **ریشهٔ پروژهٔ Next.js** استخراج کنید؛ فایل‌های هم‌نام را Replace کنید و پوشه‌ها را ادغام کنید. فایل‌های دیگر پروژه را حذف نکنید.
3. `npm ci` را اجرا کنید، چون package.json و lockfile تغییر کرده‌اند.
4. `SESSION_SECRET` را در Secrets زمان اجرای Worker با رشتهٔ تصادفی حداقل ۳۲ کاراکتر تنظیم کنید. مقادیر موجود خودتان را حفظ کنید؛ هیچ رمز واقعی در ZIP نیست.
5. پس از پشتیبان‌گیری، `npm run db:push` را برای افزودن جدول و triggerهای سفارش اجرا کنید. schema در اولین درخواست نیز خودکار بررسی می‌شود. **دیتابیس را پاک نکنید و نیازی به seed مجدد نیست.**
6. `npm run build` و سپس `npm run deploy` را اجرا کنید، یا از روند Workers Builds موجودتان استفاده کنید.

این بسته فایل سورس است؛ صرفاً آپلود آن روی هاست استاتیک کافی نیست. پروژه به Cloudflare Worker و binding دیتابیس DB نیاز دارد. هیچ تغییری روی دیتابیس یا سایت واقعی شما از این محیط اعمال نشده است.

## تغییرات مهم

- کلیک + مهمان → ورود (با امکان ثبت‌نام) → بررسی محصول → برگشت به صفحهٔ اصلی و افزودن دقیقاً یک عدد؛ سوئیچ ورود/ثبت‌نام انتخاب را حفظ می‌کند.
- محافظت از آدرس برگشت، انتخاب موقت ۳۰ دقیقه‌ای و مختص همان تب؛ انتخاب‌های قدیمی نسخهٔ قبلی کنار گذاشته می‌شوند.
- اعتبارسنجی سبد، محدودیت موجودی و تازه‌سازی قیمت/موجودی هنگام جابه‌جایی صفحه و برگشت به پنجره؛ خطای storage مرورگر سایت را خراب نمی‌کند.
- سفارش و رزرو موجودی اتمی، جلوگیری از سفارش تکراری هنگام تلاش مجدد، جلوگیری از پرداخت با مبلغ قدیمی و حفظ سبد در شکست درخواست.
- شمارهٔ گیرنده جدا از شمارهٔ حساب نگهداری می‌شود. رد سفارش جدید موجودی را فقط یک‌بار آزاد می‌کند. سفارش ردشدهٔ جدید قابل فعال‌سازی دوباره نیست؛ سفارش جدید ایجاد کنید. رفتار رزرو به سفارش‌های قدیمی اعمال نمی‌شود.
- بررسی تنظیم نشست قبل از ساخت حساب؛ خواندن Secrets از محیط Worker و پیام‌های خطای فارسی.
- تخفیفات ویژه بالای محصولات: کد ۹۶۰۱۳ با ۱۵٪، کدهای ۹۶۰۱۸، ۹۶۰۲۴، ۹۶۰۳۵ با ۱۰٪. **این درصدها پیشنهادی‌اند؛ قبل از انتشار تأیید یا در src/data/special-offers.json تغییر دهید.** قیمت پایهٔ دیتابیس دست‌نخورده است.
- نورپردازی ثابت CSS، بدون particle یا کتابخانهٔ سنگین؛ حذف انیمیشن دائمی و سایهٔ پردازشی روی عکس‌ها.

## وضعیت واقعی تصاویر — مهم

هر ۵۰ محصول تصویر محلی WebP کم‌حجم دارد (مجموع حدود 0.62 مگابایت). عکس‌های قبلی حفظ شده‌اند. **۴۰ محصول باقی‌مانده فعلاً از نسخهٔ گرافیکی اختصاصیِ بهینه‌شدهٔ همان SVG محصولات استفاده می‌کنند؛ عکس فوتورئالیستی جدید برای همهٔ آن‌ها تکمیل نشده است.** ابزار تولید تصویر در این نوبت سقف ۱۰ داشت؛ خروجی‌های آن در بستهٔ نهایی استفاده نشده‌اند. برای تکمیل دقیق درخواست تصویر فوتورئالیستی باید در نوبت‌های بعدی تصاویر تازه تولید و همین WebPها جایگزین شوند. کارت‌ها «تصویر نمایشی» دارند؛ تصویر را عکس واقعی کالای فروشی تلقی نکنید.

مسیرها و هش هر فایل در FILES.json هستند. مسیر قدیمی SVG/JPG کاتالوگ دیتابیس هنگام نمایش از manifest جدید استفاده می‌کند؛ عکس سفارشی فروشنده حفظ می‌شود.

## بررسی انجام‌شده

- ۹ تست منطق و ۵ تست SQLite: موفق.
- TypeScript و ESLint: موفق.
- ساخت production Next.js و OpenNext Worker: موفق.
- تست API واقعی با D1 محلی: ثبت‌نام، نشست، ورود/خروج، مبلغ تخفیفی، رزرو، تلاش مجدد و تعارض درخواست موفق.
- تست کامل مرورگر نوشته شده ولی **اجرا نشده**: Chromium این محیط کتابخانهٔ سیستم libnspr4 ندارد. بنابراین تأیید بصری و کلیک واقعی مرورگر هنوز لازم است.
- audit وابستگی production: صفر آسیب‌پذیری شناخته‌شده. ۹ هشدار وابستگی توسعه باقی است؛ downgrade اجباری و ناسازگار انجام نشده.
- تلگرام واقعی و دیپلوی واقعی به دلیل نبود دسترسی اجرایی این سرویس‌ها تست نشده‌اند.

## تست دستی پس از انتشار

در پنجرهٔ خصوصی + یک محصول را بزنید، ورود یا ثبت‌نام کنید و مطمئن شوید صفحهٔ اصلی همان محصول را با عدد ۱ نشان می‌دهد. صفحه را reload کنید؛ عدد نباید ۲ شود. محصول تخفیفی را به سبد ببرید و قیمت آن را با سفارش مقایسه کنید. دریافت فیش و اعلان تلگرام را با یک سفارش آزمایشی کنترل کنید.
